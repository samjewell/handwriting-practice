# Handwriting practice

**[Open the editable worksheet](https://samjewell.github.io/handwriting-practice/)**

A free handwriting worksheet with light-grey Playwrite Nigeria Modern letters and separate black guides. Use it from a browser on any computer, tablet or phone; no installation or running server is needed.

## Use the worksheet

1. Open the [hosted worksheet](https://samjewell.github.io/handwriting-practice/).
2. Edit the practice text. Underscores create blank writing space.
3. Adjust the letter colour, letter size and guide thickness.
4. Choose **Print / Save as PDF** to print an A4 worksheet or save a copy.

Long rows shrink to fit; use shorter rows for larger letters. Changes stay in the current page until it is reloaded or closed. They are not saved to GitHub or synced between devices. Save a PDF to keep a finished worksheet.

The worksheet runs entirely in your browser, with no external fonts, analytics, API calls or backend. The font is embedded in the HTML. You can also download `index.html` and open it locally.

## Hosting and updates

GitHub Pages publishes `index.html` from the root of the `main` branch. Changes pushed to that branch are deployed automatically. The repository and website are public; text entered in the worksheet is processed locally in the browser.

## Font credit and licence

The embedded **Practice Letter Layer** font is a derivative of **Playwrite NG Modern Guides**, by the Playwrite Project Authors ([upstream project](https://github.com/TypeTogether/Playwrite)). The four guide-line contours were removed so letters can be coloured independently; letter shapes and OpenType shaping features were retained. Black guides are drawn as a separate SVG layer.
